# Sunfish Pond level

A ~14,950 yr lake level record from Sunfish Pond, used as a proxy for
hydroclimatic variability and plant water availability.

## Usage

``` r
sunfish_ll
```

## Format

A tibble with `299` rows and `4` columns: `age`, `lake_lvl` (cm relative
to modern), and the reconstruction bounds `UpperBound` and `LowerBound`.

## Source

Johnson et al., in review. See the Sunfish Pond vignette.

## Examples

``` r
data(sunfish_ll)
```
