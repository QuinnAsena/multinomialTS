# Sunfish Pond pollen

A ~13,800 yr pollen record organised into 5 focal taxa, a reference
group, and an estimated age per sample

## Usage

``` r
sunfish_pollen_wide
```

## Format

A tibble with `69` rows (samples) and `7` columns: `age`, the reference
group `other`, and the focal taxa `Betula`, `Fagus`, `P.strobus`,
`Quercus` and `Tsuga`.

## Source

Johnson et al., in review. See the Sunfish Pond vignette.

## Examples

``` r
data(sunfish_pollen_wide)
```
